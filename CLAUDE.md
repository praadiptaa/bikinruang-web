# Bikinruang Digital Portfolio & Content Management System

## 1. Project Overview

This project is the official digital portfolio and content management
platform for Bikinruang.

Bikinruang is a creative event fabrication, decoration, and event
property partner focused on transforming event concepts into physical,
visual, and spatial experiences.

The company works across multiple event requirements, including:

- Event Property
- Event Decoration
- Party Sets
- Corporate Events
- Stage Decoration
- Custom Backdrops
- Rental Decoration Items
- Event Desks
- Display Booths

Bikinruang operates between:

CREATIVE CONCEPT
+
DESIGN
+
FABRICATION
+
PRODUCTION
+
INSTALLATION

The platform consists of two primary areas:

1. Public Website
2. Admin Content Management System

The public website functions as:

- A digital company profile
- A service showcase
- A project portfolio
- A visual gallery
- A client acquisition platform

The admin dashboard allows authorized users to manage:

- Projects
- Services
- Clients
- Project categories
- Project galleries
- News and updates
- Media assets

The website must feel visually strong, creative, and contemporary.

The core positioning is:

FROM VISION.
BUILT UNEXPECTED.
